## 02. Problem | 문제 정의

기존 시약 관리 방식은 육안 확인과 수작업에
의존한다는 한계가 있습니다.

- 시약의 종류 및 잔량 확인의 어려움
- 반복적인 수작업 검사 및 관리
- 단일 센서 기반 판별의 한계
- 센서 위치 및 환경에 따른 측정 편차
- 체계적인 검사 이력 관리의 필요성

## 03. Solution | 해결 방안

정전용량 및 근적외선 센싱, AI 분석 기술을
활용한 비접촉 시약 검사 시스템을 개발했습니다.

- 다중 센서 기반 데이터 수집
- OCR 기반 시약 라벨 인식
- 머신러닝 기반 시약 분류 및 잔량 추정
- 자동 검사 및 사용자 인터페이스
- 검사 세션 기반 데이터 및 이력 관리

## AI-Assisted Development | AI 활용 개발 경험

OpenAI Codex를 활용하여 소프트웨어 구현,
하드웨어 제어 및 시스템 통합을 진행했습니다.

단순한 코드 생성에 의존하기보다 실제 장비의
동작과 사용자 요구사항을 기반으로 AI와 반복적으로
협업하며 시스템을 개선했습니다.

### Case 01. 사용자 중심 UI/UX 설계 및 구현

- Raspberry Pi 800×480 터치스크린 환경 분석
- 실제 화면 사진을 기반으로 가독성 문제 파악
- 화면별 정보 우선순위 및 사용자 인터랙션 정의
- Codex를 활용한 React UI 구현 및 개선
- 시약 잔량에 따른 동적 액체 높이 시각화
- 모터 이동, 측정 중, 결과 표시 화면 구분
- 미리보기 환경을 활용한 반복적인 UI 검토

### Case 02. 듀얼 스테퍼 모터 제어

- 기존 단일 Y축 제어 시스템의 한계 파악
- 좌우 모터의 실제 속도 및 동작 특성 분석
- Codex를 활용한 독립적인 듀얼 Y축 제어 코드 구현
- 층별 이동 좌표 및 HOME 위치 기준 정의
- 가감속 제어 로직 구성
- 시리얼 교정 및 Node-RED 자동화 기능 통합
- 컴파일 오류 및 장비 동작 피드백을 통한 코드 개선

### Case 03. 센서 및 AI 분석 시스템 연동

- UI, 모터, 센서 및 AI 분석 간 데이터 흐름 정의
- Node-RED 기반 서버 통신 및 API 연동
- 최신 검사 세션과 AI 응답의 일치 여부 확인
- 화면 슬롯과 실제 모터 위치의 매핑 오류 수정
- 이전 측정값이 표시되는 데이터 갱신 문제 개선
- AI 분석 결과 표시와 모터 복귀 로직 분리
- API 응답 및 빌드 결과 확인

### Case 04. AI 기반 개발 및 협업 프로세스

1. 실제 문제 발견 및 원인 파악
2. 요구사항과 장비 제약 조건 정의
3. Codex를 활용한 코드 분석 및 구현
4. 코드, 화면 및 장비 동작 검토
5. 오류 로그와 실행 결과를 기반으로 피드백
6. 반복 개선 및 시스템 통합
7. 개발 문서 및 인수인계 자료 작성

### Human-AI Collaboration

AI는 코드 분석, 구현, 디버깅 및 문서화를 지원했으며,
저는 문제 정의, 요구사항 설계, 기술적 판단,
실제 장비 조건 확인 및 결과 검토를 담당했습니다.

이를 통해 AI의 활용 가치는 단순한 작업 자동화가 아닌,
인간의 문제 해결 능력과 기술적 구현 가능성을
확장하는 데 있다는 것을 경험했습니다.

## 10. Retrospective | 프로젝트 회고

### Leadership & Project Management

프로젝트 팀장으로서 일정 관리, 역할 분배,
기술적 의사결정 및 예상치 못한 문제에 대응하며
프로젝트 운영의 전반적인 과정을 경험했습니다.

좋은 리더는 단순히 업무를 분배하는 사람이 아니라,
팀원들의 상황을 고려하고 변화하는 환경 속에서도
프로젝트가 목표에 도달할 수 있도록 방향을
제시하는 사람이라는 것을 배웠습니다.

### AI-Assisted Development

OpenAI Codex를 활용하여 사용자 인터페이스 제작,
센서 데이터 연동 및 모터 제어 기능을 구현하면서
AI가 개발 과정에 제공하는 가능성을 경험했습니다.

특히 AI를 활용하는 데 있어 중요한 것은
단순한 코드 생성이 아니라 명확한 요구사항 정의,
생성된 코드에 대한 이해, 실제 시스템 적용 및
반복적인 검증과 개선이라는 것을 깨달았습니다.

AI가 구현의 효율성을 높여줄 수 있지만,
문제를 정의하고 기술적 방향을 결정하며
결과물의 신뢰성을 판단하는 것은 여전히
인간의 중요한 역할임을 체감했습니다.

### Continuous Improvement

졸업작품에서 끝내지 않고 기존 시스템의 한계를
보완하여 한이음 ICT 공모전 수상과 졸업논문
작성까지 이어가며 지속적인 개선의 중요성을
배웠습니다.

### Human-AI Collaboration

이번 프로젝트는 AI를 단순한 개발 보조 도구가 아닌,
인간의 아이디어를 실현하고 문제 해결의 가능성을
확장하는 협업 도구로 바라보는 계기가 되었습니다.

앞으로는 AI를 활용하는 능력을 넘어,
인간과 AI가 효과적으로 협력할 수 있는 시스템과
환경을 설계하고 기술적 가능성을 실질적인
가치로 연결하는 역량을 발전시키고자 합니다.


## Retrospective | 프로젝트 회고

이번 프로젝트는 시스템 기획과 프로젝트 관리를 넘어
AI를 활용한 실질적인 개발 및 하드웨어 제작까지
경험할 수 있었던 프로젝트였습니다.

Codex를 활용하여 UI 제작, 센서 연동,
모터 제어 기능을 구현하는 과정에서
AI가 개인의 기술적 구현 범위를 확장할 수 있다는
가능성을 경험했습니다.

그러나 AI가 생성한 코드가 항상 실제 환경에서
정확하게 동작하는 것은 아니었습니다.
실제 장비의 물리적 특성, 데이터 처리 조건,
사용자 요구사항을 이해하고 이를 AI에 정확하게
전달하는 과정이 중요했습니다.

이를 통해 AI 시대에 중요한 역량은
단순히 AI를 사용하는 능력이 아니라,
문제를 정의하고 적절한 요구사항을 설계하며,
AI의 결과물을 검증하고 실제 시스템에 적용하는
능력이라는 것을 깨달았습니다.

또한 졸업작품에서 기술 고도화, 외부 공모전 수상,
졸업논문 작성까지 이어가며 지속적인 개선과
검증의 중요성을 배웠습니다.

이러한 경험은 인간과 AI의 협업 방식,
기술과 인간의 상호작용에 대한 관심으로 이어졌으며,
앞으로 인간과 AI의 역량을 효과적으로 연결하는
시스템을 기획하고 구현하는 방향으로 성장하고자 합니다.
